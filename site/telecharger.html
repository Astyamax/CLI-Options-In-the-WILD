Options in the Wild

Interface de comptage dynamique

Télécharger l'interface

L'interface graphique permet d'analyser dynamiquement le nombre d'options d'un programme en ligne de commande directement depuis votre machine. Elle repose sur Python 3.8+ et la bibliothèque Tkinter.

Python 3.8+ pip Tkinter (inclus avec Python) Linux / macOS / Windows
⬇ Télécharger l'interface (.zip)

Comment démarrer ?

  1. Extraire l'archive

    Décompressez interface_comptage.zip dans le dossier de votre choix.

  2. Installer les dépendances Python

    Dans le dossier extrait, ouvrez un terminal et lancez :

    pip install -r requirements.txt
  3. Lancer l'interface

    Exécutez le script principal depuis la racine du dossier extrait :

    python Visualisation/UI/interface2.py
  4. Analyser un programme

    L'interface graphique s'ouvre. Saisissez le nom d'un programme (ex : git, curl, ffmpeg) et cliquez sur Analyser.

⚡ Récapitulatif rapide

Copiez-collez ces deux commandes dans un terminal depuis le dossier extrait :

pip install -r requirements.txt && python Visualisation/UI/interface2.py
🔧 Dépannage — Tkinter introuvable ? Sur certaines distributions Linux, Tkinter n'est pas installé par défaut. Lancez :
sudo apt install python3-tk  (Debian / Ubuntu)
sudo dnf install python3-tkinter  (Fedora / RHEL)
